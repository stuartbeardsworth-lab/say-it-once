# Say It Once brand files

Logos and a PowerPoint template for marketing, slides and the Play Store.
They are drawn from the same logo as the app's icon (`scripts/make-icons.mjs`),
so they always match. Nothing here is part of the app itself.

## Colours

| Colour | Hex | Use |
| --- | --- | --- |
| Navy | `#20433E` | Main colour: backgrounds, headings |
| Orange | `#E8714A` | The dot, arrows and shapes only (too light for words) |
| Deep orange | `#B84F2D` | Orange words on light backgrounds |
| Cream | `#FBF8F5` | Soft backgrounds and cards |
| Slate | `#4A5A57` | Body text |

## Logos (`logos/`)

Each comes as a PNG (see-through outside the logo; use for Word, Canva,
social media and print) and an SVG (scales to any size; for designers and
printers).

| File | What it is | Use it for |
| --- | --- | --- |
| `say-it-once-logo-circle-navy-*` | The speech bubble in a navy circle | Light backgrounds; small places such as a profile picture or favicon |
| `say-it-once-logo-circle-light-*` | The same in a cream circle | Dark backgrounds or photos |
| `say-it-once-badge-navy-*` / `-light-*` | Circle with "Say It Once" inside | Profile pictures, stickers, leaflet corners |
| `say-it-once-logo-wide-for-light-backgrounds-*` / `-dark-*` | Circle with the name beside it | Letterheads, email signatures, website headers |
| `say-it-once-logo-wide-tagline-*` | Wide, with "Record it → Keep it together → Use it when you need it" | Banners, the Play Store feature graphic |
| `say-it-once-logo-stacked-tagline-*` | Badge with the tagline underneath | Posters, leaflet covers, slides |

`previews/` shows each set on light and dark backgrounds.

### Using the logo

- Leave clear space around it, about a quarter of the circle's width.
- Don't stretch it, recolour the bubble, or add shadows or outlines.
- The orange dot is the brand mark: keep it orange.
- When the logo has to be small, use a version without the tagline, so
  nothing becomes too small to read.

### Fonts

The name and tagline use **Manrope** (extra bold), the app's heading font;
the app's text uses **Inter**. Both are free under the SIL Open Font Licence
(`src/assets/fonts/manrope-OFL.txt`, `inter-OFL.txt`). The SVGs carry the
font inside them; a few design programs ignore that, so use the PNG if the
words look wrong.

## Slide template (`Say It Once slide template.pptx`)

Widescreen PowerPoint with six layouts under Home → New Slide: Title,
Section, Content, Two columns, Statement and Closing, plus example slides
and a brand guide slide. It uses Arial so it looks the same on any computer.
Delete the example slides you don't need, or save it as a PowerPoint
Template (.potx) so every new deck starts from it.

## Words

Calm, short and kind. Plain words. Never alarming. Say It Once records and
organises; it never interprets or advises on health.
