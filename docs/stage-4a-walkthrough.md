# Stage 4a walkthrough: the privacy filter and reports

The same checks run automatically on every push: the privacy property tests
(`src/shareable/privacy.property.test.tsx`), the regressions for the old
app's leaks (`src/shareable/regressions.test.ts`) and `e2e/stage4a.spec.ts`.
Please try it yourself on the Deploy Preview.

## The example record

1. [ ] Open **Building blocks (for review)** from the footer. Under **Try
   the reports**, tap **Load the example record**. You're taken to **Use my
   record**, and every screen says "Record: Example: fall at work (made up)".
2. [ ] Read the example (What happened, How it affects me, Keep track) and
   tell me if anything in it doesn't ring true. Every private entry in it
   contains the word **PRIVATE**.

## Reports

3. [ ] It says **8 private entries are not included**.
4. [ ] Choose each purpose in turn. For every one, the report below never
   contains the word PRIVATE.
5. [ ] Choose **A PIP claim or review**. The report has sections for how it
   affects you, changes, treatment, contacts, appointments, notes and
   documents, an **Evidence index** numbering the letters E1, E2, E3, and a
   **Confirmation** with lines to sign.
6. [ ] Above it, **Before you share this** lists the personal information it
   includes (using the toilet, mixing with people, check-ins).
7. [ ] Choose **Getting ready for an appointment**. It's short, with the next
   and most recent appointments, and has no signature lines.
8. [ ] **Print** shows the report only, without the app's menus.
9. [ ] **Read aloud** reads the report in the phone's voice; **Stop reading
   aloud** stops it.

## Work details

10. [ ] In your own record, choose **Industrial Injuries Disablement
    Benefit**. It asks you to add your work details. Add an employer: the
    pack now includes it. (You can also add them from What happened.)

## Tidying up

11. [ ] In **My records**, show your own record again, and delete the
    example if you like.
