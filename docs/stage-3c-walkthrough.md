# Stage 3c walkthrough: Find, support and help

The same steps run automatically on every push in `e2e/stage3c.spec.ts`.
Please try them once yourself on the Deploy Preview. Tick each box as you go.

## Find in my record

1. [ ] On Home, tap **Find in my record**. With nothing typed, **Quick
   answers** shows money spent and lost, the medication you're taking and
   your next appointment, all from your own entries.
2. [ ] Type a word you know is in your record, such as a name or a
   medicine. Every entry containing it is listed, with the words around it.
3. [ ] Use **Show** to narrow it down, for example to Quick Notes.
4. [ ] Tap a result. You go to the screen where that entry lives. Come back
   to Find and clear the box: it's under **Recently opened**.

## Find support

5. [ ] Open **Find support**. The urgent help (999, NHS 111, Samaritans) is
   at the top. On the iPhone, tapping a number offers to call it.
6. [ ] Open a group, such as Brain injury and stroke. Each organisation's
   website link opens its own site in a new tab.
7. [ ] **Please check every name, number and website** in
   `src/content/support.json`. You can edit that file on GitHub; no code is
   involved. Fill in `lastChecked` with the date you checked.

## Help

8. [ ] **Questions and answers**: search for "private". Read every answer
   and tell me what to change. These are drafts, written to describe only
   what the app does now.
9. [ ] **How to use**: read the four steps. **Print this guide** prints the
   steps without the menus.
10. [ ] On Home, **Keep Say It Once on your phone** appears. Tap **See how**
    and read the warning about the home screen keeping a separate record.
    Go back and tap **Not now**: it goes, and stays gone after reloading.
